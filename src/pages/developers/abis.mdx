# ABIs

Minimal human-readable ABIs for the protocol-specific contracts. Standard
Uniswap V3 ABIs (`Factory`, `Pool`, `NonfungiblePositionManager`, `QuoterV2`)
are available from the `@uniswap/v3-core` and `@uniswap/v3-periphery`
packages. Full JSON artifacts live in the repo at `contract/out/`.

## BiscottiSmartRouter

```ts
export const smartRouterAbi = [
  'function multicall(uint256 deadline, bytes[] data) returns (bytes[] results)',
  'function multicall(bytes[] data) returns (bytes[] results)',
  'function exactInputSingle((address tokenIn, address tokenOut, uint24 fee, address recipient, uint256 amountIn, uint256 amountOutMinimum, uint160 sqrtPriceLimitX96)) returns (uint256 amountOut)',
  'function exactInput((bytes path, address recipient, uint256 amountIn, uint256 amountOutMinimum)) returns (uint256 amountOut)',
  'function exactInputStableSwap(address[] path, uint256[] flag, uint256 amountIn, uint256 amountOutMinimum, address to) returns (uint256 amountOut)',
] as const
```
